# Python Mortgage Refinancing Analysis

This notebook provides the Python analytical foundation of the Mortgage Refinancing Exposure Analytics project.

It covers:
- Data preparation and validation of Freddie Mac mortgage datasets.
- Historical voluntary prepayment behaviour analysis.
- Refinancing incentive calculations using mortgage rate benchmarks.
- Interest rate sensitivity scenarios (-50, -100 and -150 basis points).
- Portfolio exposure segmentation by LTV, FICO and origination vintage.

The outputs support subsequent SQL analysis and Power BI reporting.
