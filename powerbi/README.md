# Power BI Dashboard

This folder contains the Power BI dashboard screenshots developed for the **Mortgage Refinancing Exposure Analytics** project.

The dashboards present portfolio-level refinancing exposure, exposure concentration, and management insights based on the analytical outputs from Python and SQL.

## Dashboard Pages

### 1. Portfolio Exposure

![Portfolio Exposure](01_portfolio_exposure.png)

Provides an overview of mortgage portfolio refinancing exposure and key portfolio metrics.

### 2. Exposure Concentration

![Exposure Concentration](02_exposure_concentration.png)

Presents portfolio exposure segmentation to support analysis of refinancing sensitivity across borrower and loan characteristics.

### 3. Management Insights

![Management Insights](03_management_insights.png)

Summarizes analytical findings to support portfolio monitoring and management decision-making.

## Analytical Workflow

**Python → SQL → Power BI**

- **Python:** Data preparation, historical prepayment analysis, and interest rate sensitivity calculations.
- **SQL:** Data validation, portfolio aggregation, and exposure segmentation.
- **Power BI:** Visualization and communication of portfolio-level findings.

## Repository Note

The Power BI `.pbix` file is not included in this public portfolio repository because it contains underlying loan-level data. Dashboard screenshots are provided to demonstrate the reporting outputs.

For the complete project overview, refer to the [main README](../README.md).
